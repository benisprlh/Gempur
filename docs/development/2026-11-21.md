## Perubahan

Audit source menemukan grant berbagi tersimpan dapat hidup kembali setelah proses mati tanpa onDestroy, lalu peserta memilih deteksi lokal saja. Token consent proses baru sebelumnya dapat membuat grant lama kembali memenuhi dispatchStillCurrent. Ini analisis jalur kode, bukan reproduksi HP.

Saat memulihkan consent lokal tanpa token yang masih hidup, aplikasi kini memanggil penghentian durable langsung sebelum menyimpan pilihan dan menerbitkan token baru. Jika vault gagal ditulis, aktivasi berhenti. Grant lama OFF, binding unggah dibersihkan, riwayat tetap tersedia dan pending server-off terikat origin/account/pair/version/UUID dipertahankan. Consent berbagi baru ditahan sampai sinkronisasi. Token yang masih hidup tidak memicu recovery ini. OOM/crash juga memerlukan sinkronisasi penghentian dan consent berbagi baru saat peserta mengaktifkan deteksi lokal kembali. Tidak ada perubahan model, payload, schema database atau aturan blokir.

## Riset primer dan konsekuensi

- [Android Task Manager](https://developer.android.com/develop/background-work/services/fgs/handle-user-stopping): Android 13+ dapat menghentikan seluruh proses tanpa callback. Jangan bergantung hanya pada onDestroy untuk memisahkan consent setelah proses mati; patch menutup jalur reaktivasi lokal.
- [Android privacy checklist](https://developer.android.com/privacy-and-security/about): fitur harus tetap menghormati pencabutan izin. QA permission/notif/lifecycle tetap terpisah dari compile/unit test.
- [Play VPN](https://support.google.com/googleplay/android-developer/answer/12564964?hl=en): pengungkapan dan affirmative consent tetap wajib; private APK bukan persetujuan Play.
- [OWASP API4](https://api-security.owasp.org/editions/2023/en/0xa4-unrestricted-resource-consumption/): batas batch/antrean tetap diperlukan. Patch tidak memperluas kapasitas DNS32/100events/10batch atau mengumpulkan aktivitas lain. Latensi DNS belum terukur di perangkat.
- [Advisory Node 11 November](https://nodejs.org/en/blog/vulnerability/november-2026-security-releases/) memuat pembaruan keamanan dependensi jaringan/SQLite; build memakai Node 24.22.3 terverifikasi, tanpa menganggap toolchain sebagai bukti keamanan deployment operator.
- [Gamban help](https://gamban.com/help) menempatkan dukungan regional/keluarga bersama pemblokiran. Akses bantuan dan koreksi tetap gate QA Gempur; tidak mengklaim efektivitas klinis dari fitur ini.
- Sumber Amikom/COMNETS diperiksa kembali; data hostname regional berlabel independen belum diperoleh. Tidak ada impor, training atau aktivasi 480 kandidat. Lihat roadmap data.

## Rilis dan kebutuhan
