## Riset primer

- OWASP membedakan pemeriksaan format dari pemeriksaan makna. Pemeriksaan reason/verdict/action kini sesuai dengan keputusan advisory pada mesin deteksi. Riwayat yang sudah tersimpan dibaca melalui jalur lama. [Input Validation](https://cheatsheetseries.owasp.org/cheatsheets/Input_Validation_Cheat_Sheet.html)
- Android memberi kendali pencabutan VPN kepada pemilik perangkat. QA tetap perlu mengukur pencabutan, pergantian VPN, DoH/IPv6, lifecycle dan latensi DNS pada perangkat. Play mensyaratkan pengungkapan dan consent untuk data sensitif yang diproses melalui penggunaan VPN. Dokumen listing dan Data Safety harus dinilai terhadap build biasa yang benar-benar akan didistribusikan. [Android VpnService](https://developer.android.com/reference/android/net/VpnService) · [Play VPN](https://support.google.com/googleplay/android-developer/answer/12564964?hl=id)
- Rilis keamanan Node 11 November memperbarui dependensi jaringan dan SQLite. Toolchain resmi diperiksa sebelum verifikasi baru. [Advisory Node.js](https://nodejs.org/en/blog/vulnerability/november-2026-security-releases/)
- Gamban menyediakan akses dukungan bagi peserta dan keluarga. Pilot Gempur tetap memeriksa akses bantuan serta peninjauan salah klasifikasi, bersamaan dengan kontrol pemblokiran. [Gamban help](https://gamban.com/help)

## Verifikasi

Full standalone schema 3 PASS pada 09.30 WIB: 147 tes (96 Node, 25 engine, 13 client biasa, 13 client privat), tanpa skip/failure. Lint kedua varian 0 issue. APK biasa/privat, AAB biasa unsigned, kompilasi instrumentation, signature APK, isolasi manifest/BuildConfig/assets serta integritas V1 lulus. `--check-evidence` menghasilkan `valid:true`, `mergeEligible:true`. Fingerprint sebelum/sesudah sama: `adee67d9735eec77720a922df7c6bd19084e52aebd2adef17c564f750051097b`. [Bukti tersanitasi](../evidence/2026-11-20-advisory-report-build.json).

Review independen PASS; 20 tes backend terfokus juga lulus saat review awal run. Toolchain Node 24.22.3, JDK 17.0.21.1+2, Gradle 8.11.1 dan SDK 36 diverifikasi terhadap checksum penerbit resmi. ADB kosong. Instrumentation hanya dikompilasi; tidak ada hasil emulator, HP, latensi DNS, baterai atau notifikasi dua HP. APK debug memakai identitas development run ini; kompatibilitas signer terhadap instalasi peserta belum dibuktikan.

## Upgrade dan rilis

Jika antrean lama mengandung name_heuristic/blocked, server baru menolak batch. Jalur penolakan yang sudah tersedia menghentikan berbagi lokal dan menyimpan penanda server-off. Peserta perlu menyinkronkan penghentian sebelum memberi izin baru. Riwayat lokal tetap tersedia. Menonaktifkan grant mengikuti penghapusan temuan server yang sudah ditetapkan kontrak. Bukti perilaku transport dan upgrade di HP masih diperlukan.

Pilot 14 hari dimulai setelah dua Android dewasa yang disetujui lulus lab melalui USB atau HTTPS operator. Upgrade instalasi lama memerlukan APK terpasang sebagai acuan dan signing asli di lingkungan pemilik kunci. Siapkan pengukuran baterai, notifikasi, izin, Accessibility, fungsi penting dan koneksi APK. Play tetap menunggu QA, akun developer, upload key, URL privasi/penghapusan, kontak operator dan closed testing sesuai akun.

V1 tetap beku, advisory dan default-off. Tidak ada training atau domain produksi tambahan. Recall proxy Indonesia historis 7/443 dan jumlah label independen tetap nol. Gate auto-quarantine masih NO-GO.
