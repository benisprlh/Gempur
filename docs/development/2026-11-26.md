## Perubahan dan batas

Tool `node tools/audit-domain-review.mjs INPUT.json` mengaudit metadata review hostname berikutnya secara offline. Manifest memuat hash domain/keluarga/evidence/snapshot, pseudonymous IDs, source/license assertions, waktu, partition dan catatan review. Output hanya jumlah+hash input, bukan hostname atau payload review. Schema exact menolak URL/email/hostname fields; hash bukan anonimisasi dan manifest tetap dapat sensitif. Jangan commit catatan nyata atau data keluarga ke repo publik.

Duplikasi target/reviewer dan keluarga hash lintas partition ditolak. Dua reviewerID berbeda yang sama-sama mengaku human dan setuju pada label non-uncertain menghasilkan consensusCandidate; ini tidak membuktikan dua manusia independen, isi situs, lisensi atau representativitas. Konflik, uncertain dan proxy/automated tidak dipromosikan. independentlyVerifiedLabelCount tetap0 dan autoQuarantineEligiblefalse. Tidak ada download/kunjungan target/model fit atau aturan produksi. Family hash ditentukan operator, bukan groupingPSL otomatis. Tidak ada pembuktian source/time holdout dari tool ini.

Contoh sintetis dalam panduan benar-benar dijalankan pada host: exit0,1record,1consensusCandidate dan0independentlyVerifiedLabelCount. Tidak ada anotasi manusia dihasilkan oleh contoh ini.
