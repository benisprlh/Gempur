# Pengembangan 19 November 2026

Basis main `5b9f09c120811b16e2e8aa103304f9eeabeccfbc` ([PR #13](https://github.com/benisprlh/Gempur/pull/13)). Kandidat lokal 0.3.7-alpha.1/code 10.

## Hasil

Validasi sebelumnya menerima kombinasi name_heuristic/suspected/blocked walau mesin saat ini hanya memberi tanda tinjauan. Android dan server kini menolak kombinasi tersebut untuk laporan baru domain maupun paket. Server memvalidasi seluruh batch sebelum menulis. Aturan domain eksplisit tetap dapat melaporkan blocked.

Riwayat server dibaca dengan tindakan yang sudah tercatat. Tes memakai baris sintetis lama dan membuktikan list, read acknowledgement dan export tetap tersedia. Tidak ada perubahan skema. Antrean lokal lama dengan dugaan nama berstatus blocked masih dapat dikirim oleh klien lama, lalu ditolak server. Jalur penolakan yang sudah ada menghentikan berbagi lokal dan menyimpan penanda server-off. Peserta perlu menyinkronkan penghentian sebelum memilih izin baru. Kebijakan menonaktifkan grant menghapus temuan server sesuai kontrak yang sudah berlaku.

## Riset primer

- OWASP membedakan validasi sintaks dari validasi makna. Kombinasi reason/verdict/action diperiksa di Android dan API agar laporan tidak menggambarkan tindakan yang tidak didukung. [OWASP Input Validation](https://cheatsheetseries.owasp.org/cheatsheets/Input_Validation_Cheat_Sheet.html)
- Android mendokumentasikan CA sistem serta pengecualian trust untuk debug. MASVS-NETWORK menekankan autentikasi endpoint. Lab USB tetap memakai loopback dan jalur jarak jauh tetap memerlukan HTTPS. Pengujian DNS/DoH/IPv6, VPN kedua dan baterai menunggu perangkat. [Android Network Security](https://developer.android.com/privacy-and-security/security-config) · [MASVS](https://mas.owasp.org/MASVS/08-MASVS-NETWORK/)
- Node.js 24.22.3 dipakai setelah rilis keamanan 11 November yang memperbarui SQLite dan komponen jaringan. Versi JDK dan checksum toolchain dicatat di bukti. [Advisory Node.js](https://nodejs.org/en/blog/vulnerability/november-2026-security-releases/)
- GamCare menempatkan pemblokiran bersama dukungan, dan Gamban menyediakan jalur pelaporan kesalahan kategori. Gempur tetap membutuhkan koreksi dan tinjauan manusia untuk dugaan nama. [GamCare](https://www.gamcare.org.uk/self-help/blocking-software/) · [Gamban help](https://gamban.com/help)

- Pool regional Tranco/Common Crawl dan organisasi penelitian defacement ditinjau ulang. Metadata belum menyediakan label hostname negatif independen yang siap dipakai. Tidak ada impor atau pelatihan. [Roadmap data](../LOCAL_AI_DATA_ROADMAP.md#pemeriksaan-19-november-2026)

## Publikasi dan rilis

Repo public dapat di-clone. Pencarian plugin menunjukkan integrasi GitHub belum terpasang, dan `gh auth status` melaporkan belum login. Run ini tidak dapat membuat branch/PR atau memeriksa proteksi branch dengan akses autentikasi. Perubahan disiapkan sebagai patch dan bundle git. Penggabungan perlu source yang cocok dengan main terbaru, verifikasi penuh maksimal 24 jam dan proteksi yang berlaku saat akses pulih.

Pilot dua HP menunggu dua Android dewasa yang disetujui, lewat USB atau HTTPS operator. Upgrade instalasi lama memerlukan identitas signing asli dan versionCode lebih tinggi. Play menunggu QA, akun, upload key, URL privasi/penghapusan, kontak pengelola dan closed testing sesuai akun. Jadwal pilot 14 hari dimulai setelah lab lulus.

V1 tetap beku, dengan proxy recall Indonesia 7/443 dan nol label independen. Tidak ada training baru atau domain produksi tambahan. Validasi laporan tidak menambah bukti akurasi model. Auto-quarantine masih NO-GO.

Tindak lanjut pada 20 November memulihkan patch dan mengulang verifikasi untuk publikasi setelah akses GitHub kembali. [Laporan terbaru](2026-11-20.md).
