## Perubahan

`node tools/check-private-lab.mjs PARTICIPANT_SERIAL COMPANION_SERIAL [PORT]` membaca status dua serial pilihan dan memeriksa pemetaan `tcp:PORT` ke port host yang sama. Probe health menghubungi `127.0.0.1` secara langsung, dengan batas waktu dan ukuran respons. Output membedakan perangkat yang belum terdaftar, otorisasi belum diberikan, pemetaan yang salah, atau capability backend yang belum aktif. Output tidak menyertakan serial, respons mentah atau data akun. Alat tidak membuat pemetaan, memasang APK, atau membaca data aplikasi. [Panduan lab](../PRIVATE_TEST_GUIDE.md#sambungkan-server-uji)

## Riset primer

- Dokumentasi Android membedakan perangkat yang terdaftar dari perangkat yang sudah selesai boot. AOSP membedakan pemeriksaan `reverse --list` dari pengaturan reverse. Panduan menambahkan `--no-rebind` untuk mencegah konfigurasi manual menimpa pemetaan yang sudah dipakai. [ADB](https://developer.android.com/tools/adb) · [AOSP uji reverse](https://android.googlesource.com/platform/packages/modules/adb/+/3902f3fad78aee3c2e5c7b466ee64725160e3e83/test_device.py)
- Node mendokumentasikan proxy environment pada HTTP Agent. Probe memakai Agent khusus tanpa proxy, setelah review menemukan `fetch` dapat mengikuti konfigurasi proxy global. Verifier memakai 24.22.3 dengan patch keamanan 11 November. Uji proxy menegaskan permintaan tetap pada loopback. [Node HTTP](https://nodejs.org/api/http.html#built-in-proxy-support) · [Advisory Node.js](https://nodejs.org/en/blog/vulnerability/november-2026-security-releases/)
- OWASP mendeskripsikan kendali shell dan transfer yang tersedia di ADB. Preflight memakai perintah daftar saja. Untuk koneksi jarak jauh, operator tetap memerlukan HTTPS dengan endpoint tepercaya. Closed test Play pada akun personal yang tercakup memerlukan 12 tester opt-in berturut-turut selama 14 hari. Pilot privat dua HP memiliki gate sendiri. [OWASP ADB](https://mas.owasp.org/MASTG/techniques/android/MASTG-TECH-0001/) · [Play closed testing](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en)
- Gamban dan GamCare menempatkan alat blokir bersama jalur dukungan. QA Gempur tetap mencakup akses bantuan dan koreksi saat mode deteksi backend dimatikan. [Gamban](https://gamban.com/help) · [GamCare](https://www.gamcare.org.uk/self-help/blocking-software/)
- Riset data meninjau sumber tangkapan situs dan unggahan sosial berlabel. Belum ada holdout hostname Indonesia yang memenuhi syarat independensi, lisensi, waktu dan keluarga baru. Pemblokiran seluruh host media sosial tidak dapat disimpulkan dari label satu unggahan. [Roadmap data](../LOCAL_AI_DATA_ROADMAP.md#pemeriksaan-18-november-2026)

## Validasi

Verifier penuh lulus 143 tes (94 Node, 25 engine, 12 klien biasa, 12 privat). Kedua lint 0 temuan. Signature APK, isolasi varian, integritas V1 dan review independen lulus. Pemeriksaan ulang evidence mengembalikan `valid:true` dan `mergeEligible:true`. AAB biasa unsigned dibangun, instrumentation dikompilasi. Run awal ditolak karena source berubah saat perbaikan probe. Bukti hanya memakai run penuh pada source final dengan fingerprint `9d8161b5853ab4880624e93b5f5b542d41ad7124480c7e35ab898e10b58ddad0`. [Bukti build](../evidence/2026-11-18-private-lab-preflight-build.json)

Lima tes preflight memakai ADB fixture dan backend host. Tes regresi merekam nol request pada proxy lokal. Uji CLI memakai backend dan ADB nyata tanpa perangkat, lalu mengembalikan `private_enabled`, dua `not_listed` dan exit 1. Pemetaan fisik, koneksi APK dan perilaku dua HP belum diuji.

## Status rilis

Uji pairing, consent, notifikasi, koreksi, latensi DNS, baterai dan lifecycle membutuhkan dua Android dengan persetujuan serta USB atau backend HTTPS milik operator. Verifikasi koneksi dari APK dan catat browser, DoH/IPv6, VPN kedua, aksesibilitas dan pencabutan saat offline. Jika ada instalasi privat lama, pertahankan data. Upgrade tetap memerlukan sertifikat yang sama dan versionCode lebih tinggi.

Pilot 14 hari dimulai setelah lab lulus. Jalur Play menunggu QA, akun, upload key, URL privasi/penghapusan, kontak operator dan closed testing sesuai akun. V1 tetap beku dan memberi tanda dugaan, dengan Indonesia historis 7 dari 443 proxy positif dan nol label yang ditinjau independen. Auto-quarantine masih NO-GO.
