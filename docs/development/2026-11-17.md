# Pengembangan 17 November 2026

Basis main `03f4db8be45383589dc656a56ac43b628a55f644` ([PR #11](https://github.com/benisprlh/Gempur/pull/11)). Perubahan tooling. Kandidat aplikasi tetap 0.3.6-alpha.1 dengan versionCode 9.

## Perubahan

Tool `tools/sign-private-upgrade.mjs` menerima evidence penuh yang masih berlaku, APK lama dan path output baru. Tool mengambil APK privat yang tercatat dalam evidence, mengecek ulang hash salinannya, menandatangani dengan identitas di lingkungan pemegang kunci, lalu memverifikasi signature, application ID dan versi. Ia hanya membuat output bila sertifikat cocok dengan APK lama dan versi meningkat. APK input dan output yang sudah ada dipertahankan. Proses ini berjalan offline tanpa ADB atau instalasi. [Panduan signing](../SIGNING.md#buat-apk-upgrade-privat)

## Riset primer

- Android memeriksa sertifikat saat memasang pembaruan. `apksigner` menerima keystore, password melalui environment dan path output terpisah. Tool baru mengaitkan proses tersebut dengan evidence build dan APK lama. [Signing Android](https://developer.android.com/studio/publish/app-signing) · [apksigner](https://developer.android.com/tools/apksigner)
- OWASP membedakan identitas debug dari identitas distribusi. Panduan Gradle menyarankan agar file kredensial terlindung dan tidak ada pada build yang tidak dipercaya. Langkah signing privat memakai SDK setelah build selesai. Sandi hanya diberikan ke proses signing. [OWASP MASTG](https://mas.owasp.org/MASTG/knowledge/android/MASVS-RESILIENCE/MASTG-KNOW-0003/) · [Gradle](https://docs.gradle.org/current/userguide/securing_build_tool.html)
- Play App Signing memiliki jalur upload yang berbeda. AAB biasa tetap unsigned pada verifier. Node.js 24.22.3 dipakai untuk pembaruan dependensi runtime tanggal 11 November. [Play App Signing](https://support.google.com/googleplay/android-developer/answer/9842756) · [Advisory Node.js](https://nodejs.org/en/blog/vulnerability/november-2026-security-releases/)
- Gamban memosisikan blocking bersama dukungan pemulihan. Lab Gempur tetap memeriksa akses ke fungsi bantuan, pairing, pencabutan dan false positives sebelum pilot dimulai. [Panduan Gamban](https://gamban.com/help)

- Pemeriksaan metadata regional menemukan dataset Universitas Bung Hatta yang berasal dari UT1 dan dataset survei TOMCAT. Keduanya tidak dipakai sebagai holdout Indonesia baru. [Roadmap data](../LOCAL_AI_DATA_ROADMAP.md#pemeriksaan-17-november-2026)

## Validasi

Verifier penuh lulus 138 tes (89 Node, 25 engine, 12 klien biasa, 12 privat), kedua lint 0 temuan. Signature APK, isolasi varian, integritas V1 dan review independen lulus. Pemeriksaan ulang evidence mengembalikan `valid:true` dan `mergeEligible:true`. AAB biasa unsigned dibangun dan instrumentation dikompilasi. ADB tidak menemukan perangkat. Sidik jari source `67ddb748031388babce62b9641c20d3d11ad1ebb495bc4e82020c7441c679775`. [Bukti build](../evidence/2026-11-17-private-signing-build.json)

Smoke test memakai dua sertifikat sintetis dan salinan APK versi 8 yang checksum-nya cocok dengan bukti 15 November. Versi 9 ditandatangani dengan sertifikat fixture yang sama dan lulus preflight. Tool menolak sertifikat berbeda dan versionCode sama tanpa membuat output. Payload ZIP di luar entri signature identik dan APK yang diverifikasi tetap utuh. Output fixture tidak disertakan dalam paket pengguna. Identitas signing asli dan upgrade HP belum diuji.

## Status rilis

Lab masih menunggu dua Android yang disetujui peserta/pendamping, serta jalur USB atau backend HTTPS operator. Identitas asli hanya dibutuhkan untuk upgrade instalasi yang sudah dipakai. Instalasi versionCode 9 menunggu kandidat aplikasi dengan versionCode lebih tinggi. Periksa upgrade, catatan dan grant, lalu notifikasi, izin, Accessibility, lifecycle, latensi DNS, baterai, DoH/IPv6, serta pergantian VPN di HP. Pilot 14 hari mengikuti hasil lab. Evaluasi Play tetap memerlukan QA, akun, upload key, URL privasi/penghapusan, kontak operator dan closed testing sesuai akun.

V1 dan holdout tetap beku. Tidak ada penambahan domain. Dataset regional dengan label independen tetap dibutuhkan sebelum menilai validasi Indonesia atau membuka gate auto-quarantine.
